# 对话交接包：线条跑车 LINE DRIVE（M5 完成 2026-10-07 音频+打磨）

- **summary**: M5 阶段（§3.3 音效清单 + §5 移动端适配）全部落地：①WebAudio 全合成音频（无音频文件）——引擎嗡鸣（双失谐振荡器+低通，频率随车速/氮气）+ 8 种 SFX ②触控操作模型重构 ③竖屏提示旋转 + 首局引导 ④N 键静音。**M5 收尾后用户反馈"预览时没有声音"——排查出两个致命 bug 已修**：Ⓐ `actx.createOsc()` API 拼写错误（应为 **createOscillator()**）→ ensure() 第二 try 块抛错 → actx 被置 null → **全部音效静默**；Ⓑ 振荡器创建后**未调用 start()** → 即使 actx 正常引擎也不发声。同时提升音量（master 0.4→0.55、引擎 0.12→0.30）、resume 加固（每次手势非 once、state!=='running' 检查）、标题页 AI 演示也有引擎声。验证：真实点击后 `state: running`、`engine: 0.30` ✓。

- **audio 排错技巧（重要）**：
  - 自动化环境的 `dispatchEvent(new KeyboardEvent(...))` 是**合成事件（isTrusted=false）不解锁 AudioContext**——必须用 playwright `tab.cua.click()` 真实输入
  - 诊断用 `__LD.audio.diag()` 读 { state, muted, master, engine }
  - `createOsc` 是常见拼写坑（正确：**createOscillator**）；**振荡器必须 `.start()`** 否则无声
  - **引擎声策略（用户 v2 反馈）**：持续嗡鸣太吵 → 改为**跟随加速度**：`setEngineState(speed, nitro, accel)`——加速中"增大声"（增益 = |a|×0.022 上限 0.26，音调 +18Hz）、减速中"减小声"（音调 -14Hz）、匀速静默（死区 0.8 m/s²）；起音快（τ 0.10）收音缓（τ 0.30）；main.js 用 `game.speedAccel`（τ 0.125s 平滑的加速度）驱动
  - **引擎更新调用位置**：放在 **tickOnce 内**（不是 loop 回调）——这样 `__LD.step()` 手动泵帧可驱动（后台 tab 的 rAF 会被节流）；注意 **actx.currentTime 只随真实时间推进**——同步 step() 循环测不出增益爬升，验证必须用真实 setTimeout 驱动
  - 验证数据：匀速 eng=0.03→0；加速(a=7.4) eng=0.16；刹车(a=-12.7) eng=0.26；回匀速 eng=0.001 ✓
