# 对话交接包：线条跑车 LINE DRIVE（v4.1 2026-10-07 左转匝道 off 符号 bug 修复）

- **summary**: v4 上线后用户继续测试发现**左转弯道仍把车拉到最右车道**——根本原因是 `track.js fillJunction` 匝道 off 计算里的 `e.dir * o` 双重符号。左转 dir=-1、startOff=最左车道中心（负），o 本身也是负数，`-1 * -3.7 = +3.7` ——**车被画到右侧去了**。修法：去掉 `e.dir *`，off 符号完全由 `startOff` 的符号决定（startOff 已经是出口车道中心，自然有方向），mag 部分用 `R*(1-cos(t·π/2))` 1/4 圆弧。

- **done**:
  - `track.js fillJunction` 匝道 off 计算重写：
    ```js
    const mag = i < rampA
      ? R * (1 - Math.cos(Math.PI / 2 * t1))           // 0 → R
      : R * (1 - Math.cos(Math.PI / 2 * t2));          // R → 0
    off[i] = e.dir * (Math.abs(startOff) + mag);
    ```
  - crs（曲率）保持 e.dir 符号传递（主车头朝向 = e.dir 方向）
  - 验证：玩家选 jLS 最左车道 → 匝道在屏幕**左下方**走 90° 大弯（不再被画到右车道）；镜头偏航 25° 正确左转；HUD「按住 ← 过弯」与车头方向一致
