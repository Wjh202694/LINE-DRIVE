# 对话交接包：线条跑车 LINE DRIVE（v4.8 2026-10-07 匝道整条曲线 + 双弧按键 + 提示牌误报修复）

- **summary**: 用户三项反馈：①匝道要"连贯的漂亮的一整条曲线"（不是独立曲线小块拼接）②S 形匝道双弧都要按住方向键（左弧按左、右弧按右，按错飞出匝道）③转弯提示牌出现但没有弯。修复：①匝道渲染从"逐段独立小块"重构为"整条一次路径绘制"——收集所有可见匝道段的投影点后走标准平滑折线（左右路缘各一条 quadratic 链，一次 stroke）②turnRamp 对两弧都设置，方向=crs 符号，玩家在拐点切换按键，grace 覆盖两弧前段 ③删除 fillSlope 里上下坡段错放的 csign 弯道预告牌。

- **done**:
  - **匝道整条曲线（render.js）**：
    - 删除段循环里的 `if (seg.br)` 逐段渲染块
    - 新增 `drawRamps(ctx, cam, game, D, scr)`（段循环后调用）：
      - 收集匝道所有可见段（k 在 [1,D] 内）的投影点 → 模块级 RX/RY/RW/RI 数组（零 GC）

  - **S 形双弧按键（track.js）**：
    ```js
    if (Math.abs(r.crs[i]) > 0.0011) {
      const bendDir = r.crs[i] > 0 ? 1 : -1;     // 弧的弯曲方向
      const inGrace = i < RAMP_GRACE || (i >= rampA && i < rampA + 8);
      (s.turnRamp)[r.dir] = { dir: bendDir, half: r.half, grace: inGrace };
    }
    ```
    验证：右转匝道 i=0-12 `1g` → i=16-28 `1`（强制按右）→ i=32-36 `-1g`（切换缓冲）→ i=40-76 `-1`（强制按左）✓
    玩家按错 → car.js 现有外漂逻辑（holdDir ≠ turn.dir）→ 撞栏失败 ✓
    HUD 提示自动跟随 turn.dir 显示「按住 ←/→ 过弯」✓
  - **提示牌误报（track.js）**：删除 fillSlope 里 `t>0.55&&t<0.6` 处放的 csign/sign——上下坡段没有弯道，预告牌误导玩家。现在 csign 只在 S 弯（fillSCurveBends）、fork_sign 只在岔路（fillJunction）
