# 对话交接包：线条跑车 LINE DRIVE（v4.6 2026-10-07 匝道连贯性修复——off 瞬跳 bug + 相机跟随）

- **summary**: 用户反馈"匝道断裂成两部分 + 跑车被强制拉回"——**根因是 track.js 匝道 off 公式第二段的数学 bug**：`mag = R*(1-cos(π/2·t2))` 让第二段从 0 重新涨到 R（而不是从 R 减回 0），导致 off 序列在 i=rampA 处从 ±33.63 **瞬跳回** ±3.63（30m 突变）——渲染上匝道断成两截、玩家 p.x 目标突变被"拉回去"。修复：第二段改为 `mag = R*cos(π/2·t2)`（R→0，衔接上一段末值）。同时把 forkDiv 7.5→30（此前匝道横向只偏 7.5m 近乎直线，"大弯"视觉不足）、rampSegs 64→32（短促弯出=大离开角）、相机滞后参数修正（匝道段 τ 0.06、yaw 钳制 ±0.12）。

- **done**:

- **关于"左右对称"（用户期望的核对结论）**：
  - 几何定则：**匝道的凸起方向 = 转弯方向 = 按键方向**；主道始终出现在匝道的外侧（凸起方向的对面）
  - 左转匝道：从主道最左车道分出 → 向左凸 → 按住← → 主道在其**右侧**淡入 → 汇入主道最左车道（贴近匝道的车道）
  - 右转匝道：从主道最右车道分出 → 向右凸 → 按住→ → 主道在其**左侧**淡入 → 汇入主道最右车道
  - 两者严格镜像对称 ✓（e.dir 符号驱动一切）
  - 注：用户描述"左转→主道在匝道左侧"与物理几何相反（左凸匝道的外侧在主道右侧）。当前实现遵循物理+按键一致性。若用户坚持"同侧"（左转→主道在左），需要把"左转"匝道改为"从最右车道分出的右凸匝道"——但这会破坏"左转=左车道+按住左"的既有设定，需用户明确取舍。
