# 对话交接包：线条跑车 LINE DRIVE（v4.5 2026-10-07 匝道路径分离渲染——主线淡出/淡入）

- **summary**: 用户指出严重结构问题——之前的"匝道"只是主线的横向偏移带（主线永远渲染），玩家在匝道上视觉上仍在主干道，匝道像"消失"，是"偷懒用已生成好的主干道代替匝道"。v4.5 改为**真正的路径分离渲染**：mainlineAlpha 单通道，玩家进匝道后主线 3 秒内淡出（画面只剩匝道道路 + 天空背景），匝道转弯快结束时主线 3 秒内淡入，随后汇入。同时匝道改为完整道路渲染（路缘实线 + 中央虚线，无护栏），匝道出入口区段主线护栏完全移除（noRailL/noRailR 标记）。

- **done**:
  - **track.js**：`fillJunction` 新增 noRail 标记——`[forkStart-12, mergeEnd+12]` 区段按匝道方向打 `s.noRailR=1`（右转）/`s.noRailL=1`（左转）；seg 初始化加 `noRailL/noRailR` 字段
  - **main.js**：新增 `game.mainlineAlpha` 通道：
    ```js
    let mlTarget = 1;
    if (p.brDir !== 0 && game.jn && game.jn.phase === 'bend') {
      const j = game.jn.j;
      const distToMerge = ((j.mergeZ - pzNow) % track.length + track.length) % track.length;
      const fadeDist = Math.max(60, p.speed * 3.2);   // 3 秒 × 当前速度
      mlTarget = distToMerge > fadeDist ? 0 : 1;      // 远离汇入点 → 淡出；接近 → 淡入
    }
    const rate = dt / 3;                               // 3 秒完成 0→1
    game.mainlineAlpha += clamp(mlTarget - game.mainlineAlpha, -rate, rate);
    ```
    `beginRun` 重置 `game.mainlineAlpha = 1`
  - **render.js**：
    - 主线渲染 alpha = `fogA × game.mainlineAlpha`（`a *= game.mainlineAlpha`）；主线完全淡出时跳过无匝道段绘制（`mlHidden` 优化）
    - 匝道渲染 alpha **独立于主线**：`aB = fogA × rampVis`，`rampVis = onRamp ? 1 : brFade`（玩家在匝道上 → 全程可见；走主线 → 分叉端可见）
    - 匝道路面渲染重写：路缘实线（lw × 1.3）+ 中央虚线（每 6 段 2 段）；**移除矮路缘石立柱**（用户要求无护栏）；**移除金色分流鼻**（近处 PS[k] 像素尺度爆炸成巨大金色块 bug）
    - 主线护栏 gap 改用 `seg.noRailL/noRailR` 标记（替代旧 seg.br 判定）
  - **验收**（tools/qa/v4_5b_*.jpg）：

    - 02_mainline_gone：alpha≈0.17，主线淡出中（残影）
    - 03_ramp_apex：alpha=0，**主线完全消失**，画面只有匝道路缘 + 中央虚线 + 天空城市背景 ✓
