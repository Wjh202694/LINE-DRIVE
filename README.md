# 线条跑车 LINE DRIVE

黑底白线的「建筑图纸世界」里，驾驶一辆线稿跑车在无尽公路上飞驰的街机竞速游戏。
Canvas 2D 伪 3D（segment-projection），无 WebGL 依赖。

**在线试玩**：https://wjh202694.github.io/LINE-DRIVE/

设计方案见 `../线条跑车_游戏设计与制作规划.md`（WorkBuddy/创意工作）。
项目文档：[当前状态](./线条跑车_当前状态.md) · [开发历程](./线条跑车_开发历程.md)

## 运行与构建

```bash
npm install
npm run dev              # 开发服务器（默认 5173，本机常驻 5181）
npm run preview          # 本地预览构建产物
npm run build:pages      # GitHub Pages 构建（base=/LINE-DRIVE/）
npm run build:single     # 单文件版 → dist-single/index.html（3.5MB，可离线双击玩）
```

**部署**：`git push origin master:main`（源码）+ 将 `dist/` 推到 `gh-pages` 分支（Pages 源）。
Pages 配置：Settings → Pages → Deploy from a branch → `gh-pages` / (root)。

## 操作

| 桌面 | 功能 | 触控 |
|---|---|---|
| ←/→ 或 A/D | 变道；待转区选道；强制转向区按住过弯 | 左右滑动 / 屏左·右 1/3 轻点 |
| ↑ / ↓（W/S） | 油门 / 刹车 | 上半屏按住 / 下半屏按住 |
| 空格 | 氮气 | 双击 |
| P / Esc | 暂停 / 回标题 | 顶部 1/6 或右下 1/4 单击 / 双指轻拍 |
| M / G | 路线图 / 图鉴 | — |
| N / F / C | 静音 / 帧率 / 弯道调试跳转 | — |

## 结构

```
src/
  config.js    全部手感/玩法参数（调校入口）
  palette.js   四主题调色板（RGB 插值 1/21 量化）
  road.js      轨道容器 + 伪 3D 投影工具
  track.js     路段系统（12 类段生成、岔路几何、查询 API）
  car.js       主车状态机（速度/变道/强制转向/完成条）
  traffic.js   障碍车池 + 变道 AI + 碰撞事件
  wire.js      车体侧视折线（侧影 + 撞毁碎线数据源）
  sprites.js   位图注册管线 + 矢量 sprite + 四档 LOD
  bg.js        背景层（天空/城市/群山/沙漠/海洋 + 天体/飞鸟）
  render.js    分层渲染器
  fx.js        火花/碎线/速度线/氮气尾焰/震动
  ui.js        HUD/标题/结算/完成条
  menu.js      路线图 + 图鉴（M4）
  video.js     开场视频（M4）
  audio.js     WebAudio 合成音频（M5）
  input.js     键盘 + 触控
  main.js      状态机与主循环（window.__LD 调试钩子）
```

## 风格规则（写码时必须遵守）

1. 底 `PAL.bg` + 主线 `PAL.line` + 金 `PAL.gold` + 危险红 `PAL.danger`，禁第五种颜色；
2. 线宽三档：近 2.5 / 中 1.5 / 远 1 px（按屏高缩放），大气透视 100%→35%；
3. 道路线曲线化：中点二次贝塞尔（禁用多段直线拼曲线）；
4. 「车毁 = 画崩，重生 = 重画」——所有撞毁/入场/重画演出只用线段语言；
5. 预告牌只在真的有弯/岔的地方放；夜景素材注意反色坑（亮度转 alpha 自动检测）。
