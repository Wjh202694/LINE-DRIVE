- **summary**: 两项：①split（分岔新主干道）收心后的"新主线出现"从瞬时改为**5 秒时间驱动渐入**（alpha 0→1），背景层/对向车流/船队同步淡入——解决"前方一片漆黑→主路和景物突然出现"的突兀感 ②新增**转向完成条**机制——按住正确方向键积累进度（grace 期不计入分母），出弯时完成度 <3/4 判定"转向力度不足"失败；HUD 进度弧改为完成条 + 3/4 处阈值刻度线。

- **done**:
  - **split 渐入（main.js + render.js + bg.js）**：
    - `updateJunction`：`pz >= j.doneZ - 4` 时设 `p.absorbed = true; p.absorbedT = game.time;`（不再瞬时 mainlineAlpha=1）
    - mlTarget 通道重写：`absorbedSplit` 分支按时间 `since = game.time - p.absorbedT; mlTarget = clamp(since / 5.0, 0, 1)`——5s 从 0 升到 1
    - 修复：原条件 `p.brDir !== 0` 导致 absorbed（brDir=0）后不进渐入分支——重构为 `onRamp` / `absorbedSplit` 两个独立分支
    - render.js：`drawOncoming`/`drawShips` 的 alpha 乘 mainlineAlpha
    - bg.js：`drawBackground(ctx, W, H, cy, game, track, mlA)` 新参数——所有背景层（天际线/山/沙/海/天体/飞鸟）alpha 乘 mlA
    - 验证：absorbed 后 0.55s → alpha=0.11（=0.55/5 精确）；5s 后 alpha=1，画面完整三车道新主干道 + 城市背景浮现
  - **转向完成条（main.js + car.js + ui.js）**：
    - car.js：player 加 `turnProg/turnProgLen/turnZoneLen/inTurn/lastTurnDir` 字段
    - main.js 每帧转向区逻辑：
      ```js
      if (turnNow && (!p.inTurn || dirChanged)) { 重置 }
      if (turnNow) {
        if (!turnNow.grace) {                       // grace 期不计入分母（公平）
          p.turnZoneLen += p.speed * dt;
          if (holdOk) p.turnProgLen += p.speed * dt;
        }
        p.turnProg = p.turnProgLen / p.turnZoneLen;
      } else if (p.inTurn) {
        if (p.turnProg < 0.75) doCrash(null, '转向力度不足');
        else game.fovBreathT = 0.6;                 // 成功反馈 fov 呼吸
      }
      ```
    - dir 切换（S 两弧）视为新转向区（重置）——每弧独立判定
    - ui.js：进度弧改完成条——底弧灰/完成弧金（未按变暗）/3/4 处红色阈值刻度线（达标变白）/达标圆点
    - 验证：全程按住 prog=1 → 成功（fovBreath=0.58）；压制到 0.4 后补按到 0.7 → 出弯"转向力度不足"失败 ✓
