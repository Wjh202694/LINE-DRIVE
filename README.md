# 线条跑车 LINE DRIVE

黑底白线的「建筑图纸世界」里，驾驶一辆线稿跑车在无尽公路上飞驰的街机竞速游戏。
Canvas 2D 伪 3D（segment-projection），无 WebGL 依赖，最终交付为单文件 HTML。

设计方案见 `../线条跑车_游戏设计与制作规划.md`（WorkBuddy/创意工作）。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
```

## 操作

| 桌面 | 功能 | 移动 |
|---|---|---|
| ←/→ 或 A/D | 变道（车道吸附 160ms） | 左右半屏点按/滑动 |
| ↑ / ↓ | 加速 / 刹车 | 长按加速 |
| 空格 | 氮气 | 双击 |
| P / Esc | 暂停 / 回标题 | — |
| C / F | 弯道调试 / 帧率开关（开发） | — |

## 结构

```
src/
  config.js    全部手感参数（fov/相机/速度/碰撞阈值，调校入口）
  palette.js   全局调色板（§3.2A 四主题，M1 固定墨夜）
  sprites.js   线稿 sprite 定义与预渲染（主车/轿车/卡车/公交/路灯/反光柱，含撞毁碎线数据）
  track.js     路段生成器（直路 + S 弯调试模式，路侧物布点）
  road.js      赛道容器 + segment 投影
  car.js       主车状态机（速度模型/变道吸附/氮气/弯道漂移）
  traffic.js   障碍车对象池 + 碰撞分级 + 超车/贴身判定
  render.js    分层渲染器（灭点参考→道路线稿→护栏→路侧物→车→特效）
  fx.js        火花/碎线/速度线/氮气尾焰/屏幕震动
  ui.js        HUD/标题/测绘报告/暂停
  input.js     键盘 + 触屏
  main.js      状态机与主循环（window.__LD 为开发调试钩子）
```

## 风格规则（写码时必须遵守）

1. 全部画面程序化矢量线绘，位图素材只作造型参考；
2. 线宽三档：近 2.5 / 中 1.5 / 远 1 px（1080p 基准按屏高缩放），大气透视 100%→35%；
3. 色彩纪律：底 `PAL.bg`、主线 `PAL.line`、金 `PAL.gold`、危险红 `PAL.danger`，禁第五种颜色；
4. 「车毁 = 画崩，重生 = 重画」——所有撞毁/入场/重画演出只用线段语言。
